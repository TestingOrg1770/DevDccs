title: "Langchain"
---

LangChain is an open-source framework and agent engineering platform designed to help developers build, orchestrate, and govern applications powered by large language models (LLMs).

# Key Features & Ecosystem

• Core Framework: Available in Python and JavaScript/TypeScript, LangChain provides modular abstractions for LLMs, prompt templates, chains, memory management, and external tools.
• LangGraph: An open-source agent orchestration framework used to build multi-agent workflows and stateful loops using nodes and edges.
• Deep Agents: Specialized harnesses featuring built-in planning, sub-agent spawning, and file system access for complex, multi-step tasks.
• LangSmith: A unified developer platform for testing, debugging, evaluating, and monitoring LLM applications in production.
